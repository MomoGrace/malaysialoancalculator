# LoanCalc Malaysia

A complete static website package for a Malaysia loan calculator tool site.

## Included Pages

- `index.html` - Main Loan Calculator Malaysia page
- `car-loan-calculator.html`
- `home-loan-calculator.html`
- `personal-loan-calculator.html`
- `dsr-calculator.html`
- `early-settlement-calculator.html`
- `about.html`
- `contact.html`
- `privacy.html`
- `disclaimer.html`
- `404.html`
- `robots.txt`
- `sitemap.xml`

## Deployment

Upload all files to GitHub and deploy with Vercel as a static website.

## Important Before Going Live

1. Replace `https://www.malaysialoancalculator.com` in HTML files, `robots.txt`, and `sitemap.xml` with your real domain.
2. Replace `hello@malaysialoancalculator.com` with your real contact email if different.
3. Submit `sitemap.xml` in Google Search Console.
4. Apply for Google AdSense after the website is indexed and pages are working.
5. Add AdSense code only after your Google AdSense account gives you the correct publisher code.

## Notes

Calculator results are estimates only and not financial advice.
