MalaysiaLoanCalculator clean v2 package

Use this folder to replace the files in your GitHub Desktop local repository.

Steps:
1. Extract this ZIP.
2. Open the extracted folder.
3. Copy everything inside this folder.
4. Paste into Documents > GitHub > malaysialoancalculator.
5. If Windows asks to replace files, choose Replace.
6. Open GitHub Desktop.
7. Commit message: Fix calculator pages content
8. Click Commit to main, then Push origin.
